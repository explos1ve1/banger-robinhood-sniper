# BANGER — запуск українською

Це консольний бот для пулів Uniswap V3 з WETH у Robinhood Chain. Він шукає
нові пули, перевіряє ліквідність і котирування, а в режимі `live` може
купувати токен та продавати його за заданими умовами.

## 1. Подивитися термінал без гаманця

Встанови Node.js 22 або новіший, розпакуй проєкт і відкрий його папку в
терміналі. На Windows можна відкрити PowerShell у цій папці.

```powershell
npm ci
npm run demo
```

Це офлайн-демо інтерфейсу. Воно не підключається до мережі та не торгує.

## 2. Увімкнути спостереження за мережею

Створи локальний файл налаштувань. На Windows:

```powershell
Copy-Item .env.example .env
```

На Linux/macOS: `cp .env.example .env`.

Відкрий `.env` у редакторі. Перевір `RPC_URL`, адреси контрактів і залиш
`MODE=watch`. Потім:

```powershell
npm run doctor
npm start
```

Якщо `doctor` пише про таймаут, потрібен робочий RPC Robinhood Chain.
Якщо пише про невідповідність контрактів, перевір адреси за першоджерелами
з [NETWORKS.md](NETWORKS.md). Не вимикай перевірки, щоб замаскувати помилку.

## 3. Спробувати paper-режим

```powershell
npm start -- --mode paper
```

Він читає справжні котирування, але записує умовні покупки. Гроші не
витрачаються; газ у paper-PNL не враховується. Ці результати не доводять,
що реальна торгівля дасть такий самий прибуток.

## 4. Реальні угоди

Режим `live` витрачає справжній ETH. У локальному `.env` потрібно задати
`MODE=live`, `PRIVATE_KEY` окремого гаманця та
`LIVE_ACK=I_ACCEPT_REAL_TRADES`. Ключ нікому не надсилай і не завантажуй
у GitHub. Сід-фразу бот не використовує.

Початкові ліміти: покупка `0.001 ETH`, загальний бюджет входів `0.01 ETH`,
до трьох відкритих позицій. Їх можна змінити в `.env`. Спочатку знову
виконай `npm run doctor`, потім `npm start`.

Клавіші: `p` — пауза нових покупок, `r` — продовжити, `q` — завершити
процес. Пауза залишає контроль відкритих позицій; вихід із програми
зупиняє його. Програма не продає все автоматично під час закриття.

## Що перевірено

Купівлю, продаж, отримання ETH, роботу двох роутерів і відновлення після
обриву RPC перевіряють тести з контрактами Uniswap у локальній EVM.
Реальні кошти в Robinhood Chain під час розробки не використовувалися.
PONS V2 bonding curve та Uniswap V4 у цій версії не підтримуються.

## Як завантажити в GitHub

Створи репозиторій `banger-sniper` і завантаж файли проєкту. Не завантажуй
`node_modules`, `data`, `.env` або файли гаманця. `.env.example` містить
лише шаблон і має залишатися в репозиторії.

Для Git:

```powershell
git init
git add .
git commit -m "Build BANGER sniper MVP"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/banger-sniper.git
git push -u origin main
```

`YOUR_USERNAME` заміни своїм GitHub-логіном. Репозиторій уже містить
оформлений README, банер, скрін термінала, ліцензію та GitHub Actions.
